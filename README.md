# Lean
Lean is an open-source functional programming language and interactive proof assistant developed at Microsoft Research and supported by a vibrant mathematical community. It bridge the gap between computer science and mathematics by allowing you to write code while simultaneously expressing and verifying formal mathematical proofs

# Formal Mathematics & Interactive Theorem Proving with Lean

Welcome to my **Lean 4** study repository! The goal of this project is to deepen my understanding of foundational mathematics, logic, and proof techniques by writing formally verified mathematical proofs using the **Lean 4** proof assistant.

---

## 🎯 Learning Objectives

- **Formal Logic & Reasoning**: Master propositional logic, first-order predicate logic, and constructive proof techniques.
- **Foundational Mathematics**: Rebuild core mathematical foundations from scratch—including set theory, natural numbers, real analysis, algebra, and discrete math.
- **Tactic Mastery**: Learn to use Lean's core tactics (`rw`, `simp`, `induction`, `apply`, `exact`, `grind`, etc.) to streamline formal verification.
- **Mathematical Intuition**: Bridge the gap between informal whiteboard math proofs and machine-checked logical rigor.

---
